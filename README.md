# ApplyTrack – Job Application Tracker

A personal job application tracking dashboard built with React to organize job applications, track interview progress, and visualize your job search journey in one place.

🔗 **Live Demo:** [ApplyTrack](https://apply-track-gold.vercel.app/)

## 📌 Features

- **Dashboard:** View application statistics and job search progress.
- **Application Management:** Add, view, edit, and delete job applications.
- **Search & Filter:** Find applications by company, role, status, or other available details.
- **Status Tracking:** Track applications through statuses such as Applied, Interview, Offer, and Rejected.
- **Interview Tracking:** View upcoming interviews and interview dates.
- **Analytics Dashboard:** Visualize application data using charts and statistics.
- **Persistent Storage:** Save application data using browser LocalStorage.
- **Responsive UI:** A clean, modern dashboard with a purple and lavender theme.

## 🛠️ Tech Stack

- **Frontend:** React.js, JavaScript (ES6+)
- **Build Tool:** Vite
- **Styling:** Tailwind CSS
- **Charts:** Recharts
- **Icons:** Lucide React
- **Storage:** Browser LocalStorage
- **Deployment:** Vercel
- **Version Control:** Git and GitHub

## 🚀 Getting Started

### Prerequisites

- Node.js and npm installed
- Git installed

### Installation

1. Clone the repository:

   ```bash
   git clone YOUR_GITHUB_REPOSITORY_URL
   ```

2. Navigate to the project folder:

   ```bash
   cd ApplyTrack
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL displayed in your terminal.

## 🏗️ Build for Production

Run the following command to create a production build:

```bash
npm run build
```

To preview the production build locally:

```bash
npm run preview
```

## 💾 Data Storage

ApplyTrack uses browser LocalStorage to persist application information. The data remains available in the same browser unless it is cleared or removed.

**Note:** Application data is stored locally in the browser and is not synchronized across devices.

## 🎯 Project Objective

The objective of ApplyTrack is to simplify job search management by providing a centralized dashboard for organizing applications, monitoring interview progress, and understanding job search activity.
